*bibframe-json* is a [JSON Schema](https://json-schema.org/understanding-json-schema/reference) that provide a consistently shaped JSON representation for BIBFRAME data, in the spirit of [Linked Open and Usable Data](https://linked.art/loud/) (LOUD).

Just as the [International Standard for Book
Description](https://en.wikipedia.org/wiki/International_Standard_Bibliographic_Description)
(ISBD) provides a standard, human-readable form for bibliographic information on
catalog cards, *bibframe-json* prescribes a consistent JSON serialization for
BIBFRAME data, for building tools and workflows that don't necessarily require
RDF parsing and processing.

## What the shape guarantees

- fixed vocabulary terms
- every property value is an array, even with one value
- references are plain URI strings, not `{"@id": ...}` wrappers
- no blank node carries an `@id`
- a value object has `@value` and at most one of `@type` or `@language`
- `@type` is a list of classes on a node, and a datatype string on a value
  object. Tell them apart by whether `@value` is present

Those five rules are the whole contract.

## The files

Plain JSON, served from this site, with no dependency on the Python that
maintains it.

| | |
| --- | --- |
| [`https://blue-core-lod.github.io/bibframe-json/context/bibframe.jsonld`](https://blue-core-lod.github.io/bibframe-json/context/bibframe.jsonld) | the JSON-LD context that produces the shape, 251 terms |
| [`https://blue-core-lod.github.io/bibframe-json/schema/dialect.json`](https://blue-core-lod.github.io/bibframe-json/schema/dialect.json) | one resource: a Work, Instance, Hub or Item |
| [`https://blue-core-lod.github.io/bibframe-json/schema/dialect/main.json`](https://blue-core-lod.github.io/bibframe-json/schema/dialect/main.json) | the same schema, one file per definition |
| [`https://blue-core-lod.github.io/bibframe-json/schema/cbd.json`](https://blue-core-lod.github.io/bibframe-json/schema/cbd.json) | a Concise Bounded Description |
| [`https://blue-core-lod.github.io/bibframe-json/schema/ontology.json`](https://blue-core-lod.github.io/bibframe-json/schema/ontology.json) | BIBFRAME's own domains and ranges |
| [`https://blue-core-lod.github.io/bibframe-json/example/instance.json`](https://blue-core-lod.github.io/bibframe-json/example/instance.json) | the record on the card above |

The schemas reference each other relatively, `{"$ref": "Ref.json"}` and
`{"$ref": "dialect.json"}`, so they resolve against wherever you serve them
from, this site or a copy on your disk.
